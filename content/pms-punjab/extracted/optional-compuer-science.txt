                                            SECTION -A
                                  ICT / Introduction to Computing

1.    Computers and Computing: History and evolution of computing, stages of computing, basic
      machine structure, the Von Neumann model, types of computers (supercomputer, mainframe,
      mini and microcomputers), and Computer Based Information Systems (CBIS).

2.    Number Systems and Logic: Representation of numbers, binary arithmetic, data representations,
      number base conversions, Boolean algebra, and basic operations at machine level.

3.    Hardware, I/O and Storage: Processor structure and memory structures (difference between
      primary and secondary memory, RAM and cache memory), input devices (keyboard, pointing
      devices, data acquisition devices), output devices (monitor, printer, plotter), storage media (hard
      disk drives, optical drives, flash drives, RAID arrays), and computer security and virus protection.

4.    System Software and Operating Systems: Differences between system software and application
      software, functions of the operating system, architecture of personal, server, and mobile operating
      systems, command line interface (Linux command line interface, file management and
      redirection), and utilities.

5.    Office Automation: Microsoft Office package functionalities (formatting in Word, formulas in
      Excel, presentation slides in PowerPoint, database in Access), and office automation through
      Google Workspace, OneDrive, Dropbox and note-taking applications.

6.    Data Communication and Computer Networking: Data communication model, analog and
      digital data communication, modems, transmission media, network topologies (star, bus, ring),
      LANs/WANs, network protocols, evolution of the Internet, browsers and search engines.

7.    ICT Applications and Emerging Technologies: ICT applications in learning (LMS, online
      learning), health and well-being (telemedicine, wearable devices), personal finance management
      (electronic wallet, e-commerce), and artificial intelligence in brief, and software engineering.

8.    ICT Citizenship and Ethics: Issues of intellectual property and copyright, preventing plagiarism,
      data integrity, managing misinformation and fake news, and social aspects of computing.

                               Computer Communications & Networks

1.    Introduction to Networking and Network Architectures: Concepts in networking, network
      topologies, protocol architecture and network system architecture (OSI and TCP/IP reference
      model) with considerations that apply.
2.    The Physical Layer and Transmission Concepts: Analog and digital transmissions,
      transmission mediums, noise considerations, encoding schemes, multiplexing and asynchronous
      and synchronous transmissions.
3.    The Data Link Layer and Local Area Networks: Error Control, Flow Control, Data Link
      Protocols (HDLC, PPP), MAC addressing, access schemes and Local Area Network
      Technologies (Ethernet, Token Ring).
4.    The Network Layer and Internetworking: Circuit Switching and Packet Switching, Bridging,
      Internetworking and Routing, IP addresses (IPv4 and IPv6), Subnetting and CIDR, and routing
      protocols.
5.    The Transport Layer: Transport layer protocols (TCP, UDP), Ports and sockets, connection
      setup and teardown, and Flow and congestion control.
6.    The Application Layer and Current Issues: Application layer protocols (HTTP, DNS, SMTP,
      FTP) and current issues in software defined networks and Computer Networks.
7.    Network Security and Programming Exercises: Network security issues, cryptography basics,
      firewall concepts, and programming assignments dealing with networking, routing, switching and
      protocols implementation.

                                              SECTION –B
                                             Data Structures

1.    Introduction and Complexity Analysis: The roles of data structures and algorithms, abstract
      data type (ADT), OOP, and asymptotic complexity, including Big-O notation and the analysis of
      best, average and worst-case scenarios.

2.    Linear Data Structures: Arrays, linear lists, singly and doubly and circular linked lists, sorted
      lists, stacks, queues, deques and priority queue, and their practical applications such as bracket
      checking, expression conversion, and scheduling.
3.     Recursion and Sorting Algorithms: Direct recursion and recursive tracing and divide and
       conquer approaches, along with the discussion on different sorting algorithms like bubble sort,
       selection sort, insertion sort, merge sort, quick sort, heap sort, shell sort, radix sort and bucket
       sort.

4.     Searching and Hashing: Linear and binary search, hash functions, hash collision resolution,
       open addressing, chaining and indexing.

5.     Advanced Trees: Binary tree, tree traversal, binary search tree (BST), balanced tree (AVL trees,
       M-way trees) and heaps.

6.     Graph and Advanced Applications: Graph representations (Adjacency matrix and adjacency
       list), BFS, DFS, shortest path, minimum spanning trees, topological sort, cycle detection, graph
       coloring and data compression using Huffman coding.

Suggested readings:
1.    Data Structures and Abstractions with Java by Frank M. Carrano & Timothy M. Henry

      ed.). MIT Press / McGraw-Hill.


                                          Operating Systems

1.     Introduction to Operating Systems and System Structures: History and Evolution,
       Classification of Operating Systems, System Components, System Services, Dual Mode
       Operation, Protection from Hardware/ Memory/ I/O, System Call Interface and Virtual Machines.
2.     Processes and Threads: Concept of Processes, Process Control Block, States of Process, Process
       Scheduling, Process Creation and Process Termination (fork(), wait(), exec()), Multi-Threading
       Models, Threading Issues and Thread Libraries (Pthreads).
3.     CPU Scheduling: Criteria for Scheduling, Pre-Emptive and Non-Pre-Emptive Algorithms
       (FCFS, SJF, SRTF, Priority, Round Robin, MLQ, MLFQ), Thread Scheduling, Multiprocessor
       Scheduling.
4.     Process Synchronization and Concurrency: Race Condition, Critical Section Problem,
       Software & Hardware Solutions to critical section problem (Peterson’s Solution and Test-and-Set
       lock), Mutex Locks, Semaphores, Classical Problems in Synchronization (Producer – Consumer
       Problem, Dining Philosophers Problem, Reader – Writer Problem) Monitors.
5.     Deadlock: System Model, Deadlock Characteristics, Four Necessary Conditions of Deadlock,
       Resource Allocation Graphs, Deadlock Prevention & Avoidance (Banker’s Algorithm), Deadlock
       Detection & Recovery.
6.     Memory Management: Address Binding, Logical Addresses vs Physical Addresses, Contiguous
       Memory Allocation (Text Segment, Data Segment, Heap Segment, MFT, MVT; Fragmentation),
       Paging, Page Tables and Hierarchical Inverted Page Tables, Segmentation and Paged
       Segmentation.
7.    Virtual Memory: Demand Paging, Performance of Virtual Memory, Page Replacement
      Algorithms (FIFO, OPTIMAL, LRU, LFU), Frame Allocation, Thrashing, Working Set Model,
      Memory Mapped Files.
8.    Storage Management, File Systems and Security: File Concept, Access Methods, Directory
      Structure and Disk Structure, Free-Space Management, Disk Scheduling Algorithms, RAIDs, File
      System Reliability and Protection, Security of Operating System.

Suggested readings:
1.    A. Silberschatz, P. B. Galvin, G. Gagne, Operating Systems Concepts, 10th Edition, Wiley,2018.
2.    Andrew S. Tanenbaum, Herbert Bos, Modern Operating Systems, 4th Edition, Pearson, 2014, ISBN:
      013359162X.

      0134670957.

                                       Digital Logic Design (DLD)

1.    Number Systems and Binary Arithmetic: Numerical representation, number system
      conversions, data representations, Radix and Diminished Radix Complements and Binary
      Subtraction.
2.    Boolean Algebra and Reduction of Boolean Functions: Basic theorems and properties of
      Boolean algebra, Boolean functions, standard forms (canonical forms) (minterms and maxterms),
      reduction of Boolean functions (K-maps and QuineMcCluskey method).
3.    Combinational Logic Circuits: Design and analysis techniques, design of combinational circuits
      (using gates), adders, subtractors, converters, magnitude comparators, decoders, encoders,
      multiplexers and demultiplexers.
4.    Sequential Logic Circuits: Latches, Flip-Flops (SR, D, JK, T), Analysis of clocked sequential
      circuits, State reduction and assignment, registers and Shift Registers.
5.    Synchronous and Asynchronous State Machines: Ripple and synchronous counters, timing
      sequences, Mealy and Moore Finite State Machines.
6.    Memory Units and Programmable Logic Devices: Random Access Memory (RAM), Read
      Only Memory (ROM), Programmable Logic Arrays (PLA’s), CPLDs, FPGAs, logic families
      and digital integrated circuits.
7.    Hardware Description Languages and Circuit Simulations: Overview of hardware description
      language (Verilog HDL/VHDL) and electronic design automation tools for digital logic
      simulation (MultiSim, SPICE or similar).

                                       Software Engineering
1.    Introduction and Process Models: The nature of software engineering, the motivations behind
      software engineering, and professional software engineering. Traditional process models (Linear
      sequential, Prototyping, RAD, Incremental, Spiral) as well as Agile software development process
      frameworks are covered.

2.    Requirements Engineering: Concepts of requirements elicitation and analysis, functional
      and non-functional requirements, and different perspectives on modeling such as context,
      interaction, structure and behavior as well as requirement tracing.

3.    Analysis and Modeling (structured and object-oriented): Structured analysis (Data Flow
      Diagrams, State Transition Diagrams), UML modeling (Use Cases modeling, Activity Diagrams,
      Interaction Diagrams, Domain Modeling).

4.    Architectural and Component Level Design: Architectural design patterns, Data design,
      component level design, User Interface Design and GRASP (Cohesion, Coupling,
      Information Expert, Creator, Controller, Polymorphism).

5.    Software Verification, Validation and Testing: Software verification and validation
      approaches, criteria for measuring software correctness, efficiency and performance as well as
      technical reviews and the basics of software testing and test planning.

6.    Project Management and Evolution: Software evolution, project planning and management,
      configuration management, software process improvement and software reliability and
      performance standards.

Suggested readings:

                              Database Management Systems (DBMS)

1.    Introduction and File Systems: Comparison of file systems vs database systems, data
      redundancy, structural data dependency, database environment, three-schema architecture, and
      data independence.
2.    Data Models and E-R Modeling: Survey of data models (Hierarchical, Network, Relational,
      Object-oriented) and ER modeling.
3.    Relational Model and Relational Algebra: Concepts related to relations, attributes, tuples,
      domains, keys, integrity constraints, and relational algebra operations (Selection, Projection,
      Cartesian product and Joins).
4.    SQL: Data Definition Language (DDL), Data Manipulation Language (DML), complex queries,
      subqueries, grouping and aggregation, views and security/authorization mechanisms.
5.    Database Design and Normalization: Functional dependencies, inference rules and normal
      forms (1NF, 2NF, 3NF, BCNF) within relational design.
6.     Physical Storage and Indexing: Storage structure, file organization, indexed files, hashed files,

7.    Transactions, Concurrency Control, and Database Recovery: Atomicity, consistency,

      locking, timestamps and optimistic concurrency control, deadlock and database recovery
      mechanisms.
8.    Advanced and Emerging Databases: Distributed databases, data warehousing, data mining, and
      NoSQL.
