## Safeguards

The normal Hostinger build checks reviewed MCQ copies and exact optional-note source preconditions before compiling, then generates book source metadata and Journal text from their authoritative reviewed records. Verified book wording requires actual book-text/excerpt evidence; a related author page cannot silently upgrade its status. A changed quotation, changed source image or obsolete correction anchor stops the build. These are content-integrity checks, not an automatic originality or copyright verdict.

`npm run test:editorial` covers quotation qualifications/copying, translation attribution, source drift, source/option/ID preservation, all numerical steps, transcript reading order, body/image preservation and separate dated corrections. `npm run audit:editorial` verifies the generated records, both question copies, the source inventories and imported notes. The final browser gate checks actual static/runtime quotations, official note links, source attribution, six native text readers and all six clarifications. Final results are in [verification](VERIFICATION.md).
