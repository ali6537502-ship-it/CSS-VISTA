# Original course audit

The audit inspected the actual authored data for all 30 days before replacement content was imported. It covered 480 objective items, 180 corrections and 285 worked wrong/right examples, along with definitions, rules, tables, writing tasks, checklists and examination claims. The three original audit matrices retain **328 findings** with locations, severity, proposed corrections and the source support available for each finding. They do not imply that all original rules were externally verified.

The original resource had useful strengths: accessible civic and academic examples, a recognisable daily path, original interactive practice, correction models, original-writing tasks and an existing native account system. Its correction interface already distinguished model comparison from exact-string grading. Those capabilities informed the reconstruction.

Material defects included confusing word class with syntactic function, categorical collective-noun agreement, an unsupported universal *insist on* rule, oversimplified pronoun and reciprocal restrictions, inaccurate or ambiguous selected answers, transformations that changed meaning, question/mastery-count mismatches and unsupported examiner-preference claims. Examples include `d5q2` (no suitable past form for its finished-past context), `d6q6` (punctuation defect), `d11q5` (a valid embedded question treated as faulty) and `d13q11` (no defensible option). The original key positions were A: 80, B: 302, C: 93, D: 5.

Coverage was uneven. Important morphology, noun-phrase structure, tense/aspect interpretation, non-finite syntax, information structure, regional variation, advanced analysis and discourse grammar were absent or too compressed. The new curriculum matrix distinguishes the old sequence from the progressively arranged replacement. Topic existence alone was not treated as adequate teaching or assessment.

Technical inspection covered the React/Vite/Tailwind frontend, native PHP/PDO/MySQL backend, legacy browser v3/v4 namespaces, attempt-scoped account saving, idempotent request ledger, progress measures, Mistake Notebook resolution, shared navigation and Hostinger deployment. The existing grammar tests passed before changes. Baseline browser observations are retained in `baseline-browser.json`; they found no page errors or horizontal overflow at the four tested widths. They were not a complete accessibility certification.

The new course uses a separate edition, stable IDs and a new additive table. Old authored files and keys remain unchanged to protect historical attempts; the public course route now uses the reconstructed edition in this branch. The read-only earlier-work view preserves learner notes and drafts and maps old days to new topics. The Mistake Notebook now resolves new grammar IDs and links back to the appropriate practice.

`audit-matrix.json` normalises all findings while retaining the originals. Its replacement links are topic-level traceability, not a claim that legacy records were rewritten. Any old faulty key remains an archived key, not new proficiency evidence. Unsupported examination trends were removed from the reconstructed teaching rather than replaced with invented statistics or official questions.
