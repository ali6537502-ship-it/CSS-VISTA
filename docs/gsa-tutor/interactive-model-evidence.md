## Review requirements before publication

1. Science reviewer verifies every text label and depiction, including phase direction, molecule concentration, seismic vibration orientation and water-treatment order.
2. Keyboard access, aria-pressed state, legible vector labels and responsive overflow pass browser checks.
3. Model actions change informative content, not only color or animation.
4. An accessible explanation and the authoritative source link appear with each model.
5. Do not call these interactive illustrations calibrated scientific simulations or claim that two already-existing models are comprehensively source-certified.

Source verification for **these discrete illustrative principles** does not verify unrelated statements or other textbook sections.
