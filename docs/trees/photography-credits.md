## Responsive implementation
Premium feature cards retain native button controls for joining, dashboard scrolling and planting reports. CSS grid changes from 3 columns (desktop) to 2 columns (tablet) to a single column (mobile). Layout has dedicated rules down to 320–350px and respects reduced-motion preferences. The existing logos remain a normal image, never re-sketched as CSS/SVG.
