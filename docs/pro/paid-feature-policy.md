# Paid feature policy

The owner's latest instruction supersedes historical free access for Précis, General Ability, Essay Themes, My Answer Performance and Current Affairs. The Free account list excludes those destinations. Pro includes the same free destinations plus the paid features, each with a star and visible Pro label.

## Enforcement

- Précis: the account course and subject route require Pro in the UI; native curriculum and new evaluations retain their existing Pro guards. New generic Précis drafts also require Pro, so the shared writing notebook cannot bypass paid practice. Previously earned owned writing and accepted-operation receipts remain stored under existing ownership rules. Grammar stays free.
- General Ability: the dedicated MPT/GK banks, reasoning bank, category quizzes and formula notes require Pro. Native file delivery protects central Ability shards and one-liner notes. The shared General Science/Ability file serves only science to anonymous, Free and expired accounts, and its full content to eligible active Pro accounts. The browser reloads the shared bank when membership changes.
- Essay Themes: root/detail routes require Pro, and the full roadmap JSON is served through native entitlement checks. The title/count catalogue remains metadata; checkpoint identifiers and stored local progress are unchanged.
- My Answer Performance: both its page and GET/POST native API require active Pro. Existing ownership, profile, CSRF, version, replay, mark-validation and correction safeguards remain. Expiry does not delete questions, evaluations or retries; renewal restores them.
- Current Affairs: the native daily briefing API, account reading/revision view and reading actions require Pro. Public collection data, issue files, MCQ banks, archived notes and weekly magazine PDFs use native protected delivery. Search carries issue titles rather than premium analysis. Public CMS responses exclude premium bodies; the existing MFA owner session still receives the full editorial payload.

Hostinger rewrite rules protect legacy file URLs before ordinary static-file handling, preserving bookmarks and magazine readers. Native checks also apply to direct gateway requests. Responses are private/no-store and noindex. Private issue payloads are denied by server routing and no longer compiled into browser chunks. Existing publication states, question content, exam schedules, official paper histories, storage identifiers and student data are preserved. Public official examination references remain available in their existing archives.

The existing native membership period and PKR 1,950 product configuration are unchanged. This classification does not enable payment collection or AI providers.

## Validation

The native access regression covers anonymous, Free, active and expired membership for direct resource URLs and APIs, renewal continuity, free science, protected Précis drafts/catalogue, path/helper protection and private JSON/PDF headers. Existing mentor, reading, planner, Précis and feedback workflows verify ownership and saved-record continuity with the revised paid policy in the disposable database. Synthetic accounts and outputs are used only locally or in CI.

Lint, TypeScript, all 185 standard tests and the strict Hostinger build passed. Browser checks used real native sign-in: paid cards absent from Free, nine starred Pro features plus the identical free list, direct route locks, active lesson/question/theme/PDF paths, expired membership locks, and free profile/security/Grammar/preparation flows. Widths 320–1,440 pixels had no overflow; there were no page errors or payment/provider writes. Full issue files and the paid one-liner datasets were also checked for absence from browser bundles.
