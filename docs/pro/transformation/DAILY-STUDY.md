# Guided daily study reform — development work

The daily session connects available course metadata to Learn, independent writing, the tool's feedback/checks and course-filtered Review. Students choose 15/30/60 minutes; suggested allocations are guidance, not recorded study time or completion. Native course, draft, feedback and review APIs retain authority. Topic sessions open the same topic's write/check modes. Free sessions use account writing and Grammar checks; Pro tools retain their original membership/provider gates.

A session guide appears across student tools, including public Grammar while signed in. Non-sensitive course/time/stage parameters survive step links and reload; in-memory context retains the guide when the active tool changes its own query. No identity, draft body, grade or source text is stored in these session URLs. Session context is not imported progress, a saved cross-device plan or evidence of mastery. Course availability is re-read for the current account. The guide must not silently initiate feedback/provider calls or award completion.

The shared account canvas, controls, focus treatments and card styling now apply to account routes. Individual tool layouts, complete lesson-specific writing prompts, feedback-to-revision evidence, a saved cross-device daily plan, manual accessibility and physical-device evaluation still need work. This is the first guided-flow implementation, not completion of the requested full account reform. Existing records and native workflows remain authoritative. Production release hold remains active.
