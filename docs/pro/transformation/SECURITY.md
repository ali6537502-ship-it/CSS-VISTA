Publication now additionally requires `review_manifest_id`: the SHA256 of a privately installed JSON dossier under `CSSV_PRIVATE_STORAGE_DIR/topic-reviews/`. There is no API to mint approval files. The loader checks file size/type/integrity, exact edition/content hash, separate author/reviewer references, independent evidence hash, coverage/source/assessment and owner-authorization references, approved status and valid review date. The exact dossier hash and metadata enter the existing immutable editorial event. The owner/MFA session, CSRF, optimistic revision and request receipt remain unchanged. Test-only approval files are clearly labelled synthetic and created solely by a guarded CLI fixture. This records and enforces trusted operator review evidence; it does not independently authenticate an external reviewer's signature or turn synthetic evidence into academic approval.
