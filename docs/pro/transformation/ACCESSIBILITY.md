# Bounded accessibility and browser evidence

The final local application was tested in isolated Chromium using native PHP/MySQL fixtures and the built Hostinger frontend. Seven workspace views were exercised at 320, 390, 768, 1024 and 1440 pixels; exact saved-writing navigation/Back, native-loaded legacy rich text, clipboard insertion and six sanitizer attack classes passed without page errors. These are lab checks, not a physical-device or usability panel.

The first integrated axe run found real 4.46:1 contrast failures for slate-500 on the proposed canvas. AccountPage now uses the darker secondary token for those inherited classes. The final rerun covered 25 representative account/domain screen checks with zero automated WCAG violations, one main landmark, reduced motion and the existing keyboard/menu/grading checks. The 25 incomplete contrast-rule observations remain separately recorded. Rendered review passed 88 ordinary text cases and 25 visible ticker cases, identified four decorative clock separators and left one menu-obscured text case for manual review. Passing computational measurements is not manual assistive-technology approval.

The current Free Grammar browser suite separately passed all 53 checks across 30 lessons, 13 written formats, four widths, persistence, notebook and restoration. Signed-in Grammar and six-view Grammar accessibility programs also passed. The corrected Sentence Studio journey preserves its workspace/version/attempt through v5 reference/practice while keeping Précis returns separate. The earlier v5 timeout occurred during an overlapping build; the quiescent artifact rerun passed. No build is treated as browser-readiness proof.

Outstanding: all new and legacy states under manual keyboard/AT, physical/software-keyboard devices, 200% zoom/400% reflow, complete Urdu/math reading, the remaining obscured case, real beginner/advanced task panel and representative performance/field measurements. This does not certify full WCAG conformance or satisfy the entire P6 release gate.
