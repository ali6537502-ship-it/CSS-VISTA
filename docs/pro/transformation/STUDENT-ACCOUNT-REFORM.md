# Student account reform — implementation scope

The student account uses one presentation system: six primary homes, an account hero, grouped utility navigation, consistent form controls, keyboard focus, content panels, reading statistics and writing-tool cards. Guided tools keep their native editors, feedback rules, history and save controls. Vistagram joins the same account frame without a nested main landmark. Profile/authentication panels inherit the common account control/card treatment. No account, document, assessment, membership or progress store is replaced.

Daily study connects the selected native course to Learn, Write, Feedback and Review. Topic sessions retain their own topic for writing/checks; Free sessions explicitly use saved writing and Grammar self-checks. The actual native lesson/day/section is retained when moving through Learn, without copying search text, response bodies or grades. Native tools remain responsible for actual feedback and recorded completion; session navigation does not award credit or start paid providers.

A small account-scoped sessionStorage record retains only course, native lesson location, suggested time, current step and start time for 24 hours. It is not a second progress ledger or cross-device synchronization system. Foreign, malformed, oversized and expired records are ignored. Ending a session removes only this pointer. Native course availability is checked again through an exact permission-filtered catalog lookup, including courses beyond the first page. Session controls live outside route-remount boundaries, survive native query changes/reload and never enter account identifiers into study links.

The implementation scope is the connected daily workflow and common student-account presentation, not curriculum completion, independently validated academic relevance, calibrated AI feedback, cross-device saved plans or physical-device/manual assistive-technology certification. Those remain separate gates. Production release hold remains active; this branch must remain draft and unmerged.
