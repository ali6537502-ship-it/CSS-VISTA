# General Ability course

The lesson workspace includes keyboard-operable fraction bars for fraction/decimal/percentage equivalence and movable circle/rectangle diagrams for radius, circumference, area and perimeter. These calculations are local teaching aids, make no server/model calls and award no completion. Circle outputs explicitly use the 22/7 approximation.

The owner's requested maths course is a native Pro account feature at `/account/general-ability`. The dashboard and account navigation link to it with the existing star badge. It remains available independently of the temporary MPT suspension; no MPT flag, examination schedule, frozen paper, existing bank or student history is changed.

The first authored course edition has 21 topics in three stages: numbers/place value, basic calculation, HCF/LCM, fractions, decimals, percentages and ratio/proportion; averages, profit/loss, discounts, time/work, speed/distance, age problems and word problems; number series, algebra, equations, geometry/area, circles, surface area and volume. Each topic has three lessons with a progressively revealed worked example and a separate numeric exercise, followed by a five-question quiz. This gives 63 worked examples, 63 exercises and 105 quiz questions. All are original learning material, not claimed as authentic past-paper questions. This is the initial 63-lesson curriculum, not a claim of exhaustive examination coverage.

The authored JSON and fixed keys live under the existing protected PHP payload directory. Native authentication, complete profile and actual active membership are required before lesson delivery. Answers, proof arithmetic and assessment explanations are removed from unsolved lesson responses. Submitted answers receive server-authored feedback. JSON responses are private/no-store and noindex, and direct helper/payload URLs are denied. No AI provider, paid API or live payment collection is enabled.

Exercises accept numeric decimals or equivalent fractions. Only recurring targets additionally accept rounding to two decimal places; an arbitrary near-integer or a rounded terminating decimal is rejected. The explicit numeric format note appears beside the answer field. Quizzes validate the exact five question identities and integer choices. A topic is complete only after all three exercises have a correct saved response and at least one quiz scores 4/5 or better. Viewing, revealing steps or saving a place creates no completion credit. Completion records practice, not examination mastery. Lower subsequent scores retain earlier earned completion and all immutable attempts.

Migration 024 adds only account-owned reading positions and immutable response records. It follows existing advisory-lock runtime schema initialization and indexed native MySQL/PDO queries; no existing schema or data is removed. Positions use the latest confirmed save, while results append independently and cannot overwrite another device's work. The catalogue hashes its edition; stale-edition submissions are rejected. Earlier results retain their original prompt, answer and explanation snapshot. Expiry blocks new paid work, preserves owned saved history/receipts, and renewal restores current-edition progress.

Browser-only unsent answers use new account/edition/lesson-scoped keys and do not change existing local storage. Confirmed responses and the last saved place are native account data across devices. Before a write, the browser stores its exact request identity. A lost response requires checking the account-owned receipt; only confirmed absence offers an explicit same-request retry or discard. Exact replay creates no duplicate response and remains recoverable after expiry. Request hashes distinguish this feature from other learning endpoints.
